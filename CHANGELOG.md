# Changelog

## [Unreleased]

### Изменено
- Интерфейс полностью переделан: вместо Tkinter/CustomTkinter теперь окно на WebView2 (HTML/CSS/JS), в дизайне на основе TailAdmin — тёмная/светлая тема, фиолетовый акцент, карточки, боковое меню.
- Выбор диска для загрузки заменён на выбор произвольной папки назначения через системный диалог («Обзор…»).

### Добавлено
- Экран загрузки с живым прогрессом, статистикой (скачано/дубли/пропущено/ошибки) и карточками скачанных треков.
- Экраны истории загрузок (с поиском) и сохранённых плейлистов (синхронизация/удаление).
- Экран настроек: умные дубликаты, автокаталогизация, расширенные теги, автообновление yt-dlp, число потоков.
- Заставка загрузки при старте приложения.
- Drag & Drop ссылки прямо в окно (нативно, без сторонних зависимостей).

### Исправлено
- `find_removable_drives()` мог зависать на много секунд при недоступном сетевом диске — переписано на `GetLogicalDrives()`, не трогает файловую систему.
- Диалог выбора папки (`create_file_dialog`) вызывался из фонового потока и падал с COM-ошибкой на WebView2 — теперь корректно выполняется на UI-потоке.
- Класс `Api` (мост JS↔Python) хранил объект окна и другие служебные объекты как публичные атрибуты — pywebview рекурсивно обходил их при генерации JS-моста, доходя до внутренних COM-объектов WebView2, что вызывало ошибки и зависания приложения. Атрибуты сделаны приватными.
- Вспышка светлой темы при запуске (интерфейс на миг открывался светлым, даже при тёмной системной теме) — тема применяется синхронно до первой отрисовки страницы.

### Удалено
- `gui.py`, `tooltip.py` — старый интерфейс на Tkinter/CustomTkinter, больше не используется.
- Зависимости `customtkinter`, `windnd` — заменены на `pywebview`, `pythonnet`.

### Сборка
- `.github/workflows/build.yml`: в exe теперь упаковывается папка `web/` (интерфейс), добавлен сбор ресурсов `pywebview`/`pythonnet`/`clr_loader` для корректной работы WebView2 в собранном приложении.
