# ShipTones

Десктопное приложение (Windows, Python + Tkinter) для скачивания музыки с YouTube, VK Музыки и Яндекс Музыки, конвертации в MP3 и организации библиотеки треков: история загрузок, сохранённые плейлисты, автосинхронизация на флешку и т.д.

> ⚠️ Проект использует `yt-dlp` для загрузки видео/аудио с YouTube и других сервисов. Скачивайте только тот контент, на который у вас есть права, и соблюдайте условия использования соответствующих платформ.

## Возможности

- Загрузка треков и плейлистов по ссылке (YouTube / VK Музыка / Яндекс Музыка)
- Автоопределение источника по URL
- Конвертация в MP3 с выбором битрейта (128–320 кбит/с)
- Многопоточная загрузка (настраиваемое число потоков)
- Нормализация громкости и удаление тишины (EBU R128) — опционально
- Расширенные ID3-теги (исполнитель, альбом, год, жанр, номер трека) и обложка трека
- История загрузок с поиском
- Сохранённые плейлисты и их ручная/автоматическая синхронизация по расписанию
- Drag & Drop ссылок в окно (на Windows, через `windnd`)
- Локальная база данных на SQLite (история и плейлисты)
- Авто-обновление `yt-dlp`, чтобы YouTube не блокировал загрузки

## Требования

- **Windows** (используются вызовы вроде `os.startfile`, `C:\` и т.п. — на macOS/Linux без правок работать не будет)
- **Python 3.10+**
- **FFmpeg** — обязателен для конвертации в MP3. Скачайте с [ffmpeg.org](https://ffmpeg.org/download.html) и распакуйте так, чтобы `ffmpeg.exe` лежал в одной из папок:
  - рядом с `main.py` (или в подпапке `ffmpeg-*` рядом с ним),
  - `C:\ffmpeg\bin`,
  - `C:\Program Files\ffmpeg\bin`,
  - либо просто добавьте путь к `ffmpeg.exe` в переменную окружения `PATH`.

## Установка

```bash
git clone https://github.com/KimberlyWay/ShipTones.git
cd ShipTones
pip install -r requirements.txt
```

Если `requirements.txt` ещё не добавлен в репозиторий — используйте:

```bash
pip install yt-dlp mutagen Pillow windnd
```

(`windnd` нужен только для Drag & Drop и только на Windows — без него приложение тоже запустится, просто без этой фичи.)

## Запуск

```bash
python main.py
```

При первом запуске приложение само проверит интернет, наличие FFmpeg и опциональных библиотек — статус будет виден в логе внизу окна.

## Использование

1. Вставьте ссылку на трек или плейлист в поле ввода (или перетащите ссылку в окно — Drag & Drop).
2. Выберите источник (определяется автоматически по ссылке), диск для сохранения и битрейт.
3. Выберите режим — «Один трек» или «Плейлист».
4. Нажмите **▶ Начать загрузку**.
5. Готовые треки появятся карточками ниже, лог покажет прогресс. По завершении можно открыть папку с файлами кнопкой **📁 Открыть папку**.

Во вкладке **Плейлисты** можно повторно синхронизировать ранее скачанные плейлисты, а в **Настройках** — включить автосинхронизацию по расписанию, число потоков, нормализацию громкости и т.д.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа, перехват фатальных ошибок |
| `gui.py` | Интерфейс на Tkinter (все вкладки и виджеты) |
| `downloader.py` | Логика загрузки через `yt-dlp`, конвертация, теги |
| `database.py` | SQLite: история загрузок и сохранённые плейлисты |
| `utils.py` | Вспомогательные функции: поиск дисков, FFmpeg, обложки, хэши |
| `config.py` | Настройки, цветовая палитра, логирование, список источников |
| `tooltip.py` | Всплывающие подсказки в интерфейсе |

## Известные проблемы

- Если при запуске падает `ModuleNotFoundError: No module named 'yt_dlp'` (или `mutagen`/`PIL`) — значит зависимости не установлены. Смотрите раздел [Установка](#установка).
- Если MP3 не создаются, а в логе `⚠ FFmpeg не найден!` — проверьте, что `ffmpeg.exe` лежит в одной из ожидаемых папок (см. [Требования](#требования)).
- Полный traceback любой критической ошибки сохраняется в `shiptones.log` рядом с приложением.
