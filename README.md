# ShipTones

Десктопное приложение (Windows, Python + WebView2) для скачивания музыки с YouTube (VK Музыка и Яндекс Музыка — в разработке), конвертации в MP3 и организации библиотеки треков: история загрузок, сохранённые плейлисты.

> ⚠️ Проект использует `yt-dlp` для загрузки видео/аудио с YouTube и других сервисов. Скачивайте только тот контент, на который у вас есть права, и соблюдайте условия использования соответствующих платформ.

## Возможности

- Загрузка треков и плейлистов по ссылке (YouTube; VK Музыка и Яндекс Музыка — в разработке)
- Автоопределение источника по URL
- Конвертация в MP3 с выбором битрейта (128–320 кбит/с)
- Многопоточная загрузка (настраиваемое число потоков)
- Расширенные ID3-теги (исполнитель, альбом, год, жанр, номер трека) и обложка трека
- История загрузок с поиском
- Сохранённые плейлисты и их ручная синхронизация
- Drag & Drop ссылок прямо в окно приложения
- Локальная база данных на SQLite (история и плейлисты)
- Авто-обновление `yt-dlp` при запуске, чтобы YouTube не блокировал загрузки
- Проверка обновлений самого приложения по кнопке в настройках (через GitHub Releases)
- Мгновенная отмена загрузки — обрывает текущий скачиваемый файл, а не только очередь

## Скачать готовое приложение

Проще всего — взять уже собранный `.exe`, без установки Python и зависимостей:

1. Перейдите в раздел **[Releases](../../releases)** репозитория.
2. Скачайте `ShipTones.exe` из последнего релиза (или зайдите во вкладку **Actions** → последний успешный прогон **Build EXE** → **Artifacts**, если релиза ещё нет).
3. Запустите файл — FFmpeg уже встроен внутрь, ничего доустанавливать не нужно.

При первом запуске Windows SmartScreen может предупредить про неизвестного издателя — это нормально для неподписанного exe, жмите «Подробнее → Выполнить в любом случае».

## Сборка из исходников (для разработки)

Нужно, только если хотите менять код, а не просто пользоваться приложением.

```
git clone https://github.com/shipkovivan250-cmd/ShipTones.git
cd ShipTones
pip install -r requirements.txt
python main.py
```

**Требования для запуска из исходников:**
- Python 3.10+
- FFmpeg — скачайте с [ffmpeg.org](https://ffmpeg.org/download.html), положите `ffmpeg.exe` рядом с `main.py` (или в подпапку `ffmpeg-*`), либо в `C:\ffmpeg\bin`, `C:\Program Files\ffmpeg\bin`, либо добавьте путь к нему в `PATH`.

Чтобы собрать свой `.exe` вручную (то же самое, что делает GitHub Actions):
```
pip install pyinstaller
pyinstaller --onefile --windowed --name ShipTones --add-binary "ffmpeg.exe;." --add-data "web;web" --collect-all pywebview --collect-all pythonnet --collect-all clr_loader main.py
```
Готовый файл появится в папке `dist/`.

Либо просто запушьте изменения в `main` — сборка запустится сама (см. `.github/workflows/build.yml`), и готовый exe будет ждать в Artifacts.

## Как выпустить новую версию (для владельца репозитория)

Чтобы у пользователей сработала проверка обновлений (кнопка «Проверить обновления» в Настройках), релиз нужно публиковать как **GitHub Release**, а не просто брать exe из Artifacts:

1. Поднимите `APP_VERSION` в [config.py](config.py) (например, `"1.1.0"` → `"1.2.0"`).
2. Закоммитьте и запушьте это изменение в `main`.
3. Создайте и запушьте тег с тем же номером, с буквой `v` впереди:
   ```
   git tag v1.2.0
   git push origin v1.2.0
   ```
4. `.github/workflows/release.yml` соберёт exe и опубликует его как GitHub Release с тегом `v1.2.0`.
5. У всех, кто уже пользуется более старой версией, нажатие «Проверить обновления» в Настройках скачает и поставит новую версию.

## Использование

1. Вставьте ссылку на трек или плейлист в поле ввода (или перетащите ссылку в окно — Drag & Drop).
2. Выберите источник (определяется автоматически по ссылке), папку назначения (кнопка «Обзор…») и битрейт.
3. Выберите режим — «Один трек» или «Плейлист».
4. Нажмите **▶ Начать загрузку**.
5. Готовые треки появятся карточками ниже, лог покажет прогресс. По завершении можно открыть папку с файлами кнопкой **📁 Открыть папку**.

Во вкладке **Плейлисты** можно повторно синхронизировать ранее скачанные плейлисты, а в **Настройках** — число потоков, умные дубликаты, автокаталогизацию и расширенные теги.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | Точка входа, перехват фатальных ошибок |
| `webapp.py` | Мост между интерфейсом и логикой: окно WebView2, JS API |
| `web/` | Интерфейс (HTML/CSS/JS), запускается внутри `webapp.py` |
| `downloader.py` | Логика загрузки: диспетчер по источникам (YouTube через `yt-dlp`, VK/Яндекс — в разработке), конвертация, теги |
| `updater.py` | Проверка новой версии на GitHub Releases и самообновление `.exe` |
| `database.py` | SQLite: история загрузок и сохранённые плейлисты |
| `utils.py` | Вспомогательные функции: поиск дисков, FFmpeg, обложки, хэши |
| `config.py` | Настройки, цветовая палитра, логирование, список источников |

## Где хранятся данные

Приложение не создаёт файлы рядом с exe. Всё лежит в `%APPDATA%\ShipTones\`:
- `shiptones.db` — история загрузок и сохранённые плейлисты
- `shiptones.log` — лог для диагностики ошибок
- `settings.json` — сохранённые настройки

## Известные проблемы

- Если запускаете из исходников и падает `ModuleNotFoundError: No module named 'yt_dlp'` (или `mutagen` / `PIL`) — значит зависимости не установлены. Смотрите раздел [Сборка из исходников](#сборка-из-исходников-для-разработки). В готовом `.exe` из релиза этой проблемы нет.
- Если MP3 не создаются, а в логе `⚠ FFmpeg не найден!` — актуально только при запуске из исходников. Проверьте, что `ffmpeg.exe` лежит в одной из ожидаемых папок.
- Полный traceback любой критической ошибки сохраняется в `%APPDATA%\ShipTones\shiptones.log`.
