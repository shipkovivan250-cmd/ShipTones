# 🎵 ShipTones

**Кроссплатформенный музыкальный загрузчик** для Windows, Linux (Ubuntu/Debian) и macOS с качеством звука как в YouTube Music.

> ⚠️ Проект использует `yt-dlp` для загрузки аудио с YouTube Music, VK Музыки и Яндекс Музыки. Скачивайте только тот контент, на который у вас есть права, и соблюдайте условия использования соответствующих платформ.

## ✨ Возможности

### 🔥 Основные функции
- **Мультиплатформенность**: Windows (.exe), Linux (.AppImage/.deb), macOS (.app)
- **Источники**: YouTube Music ✅, VK Музыка 🚧, Яндекс Музыка 🚧
- **Форматы**: AAC (256 кбит/с), MP3 (320 кбит/с), FLAC (без потерь), Opus (160 кбит/с)
- **Качество звука**: Нормализация -14 LUFS (EBU R128) как в YouTube Music
- **Автоопределение источника** по URL
- **Многопоточная загрузка** (настраиваемое число потоков)
- **ID3-теги**: исполнитель, альбом, год, жанр, номер трека + обложка
- **История загрузок** с поиском и фильтрацией
- **Сохранённые плейлисты** с ручной синхронизацией
- **Drag & Drop** ссылок прямо в окно приложения
- **Локальная БД** на SQLite (история + плейлисты)
- **Автообновление** yt-dlp при запуске
- **Проверка обновлений** приложения через GitHub Releases
- **Мгновенная отмена** загрузки (обрыв текущего файла + очереди)

### 🎧 Качество звука
| Формат | Битрейт | Особенности | Совместимость |
|--------|---------|-------------|---------------|
| **AAC** | 256 кбит/с | Как в YouTube Music, нормализация -14 LUFS | ✅ LADA EnjoY Pro, iOS, Android |
| **MP3** | 320 кбит/с | Максимальная совместимость | ✅ Все устройства |
| **FLAC** | Без потерь | Студийное качество, файлы больше в 3-4 раза | ✅ Hi-Fi системы, ПК |
| **Opus** | 160 кбит/с | Лучшее качество при меньшем размере | ⚠️ Новые устройства |

## 📥 Скачать готовое приложение

### Windows (.exe)
1. Перейдите в раздел **[Releases](../../releases)** репозитория.
2. Скачайте `ShipTones.exe` из последнего релиза.
3. Запустите файл — FFmpeg уже встроен, ничего доустанавливать не нужно.

> 💡 При первом запуске Windows SmartScreen может предупредить про неизвестного издателя — это нормально для неподписанного exe, жмите «Подробнее → Выполнить в любом случае».

### Linux (Ubuntu/Debian)
```bash
# Скачайте .deb пакет из Releases
sudo dpkg -i shiptones_*.deb
# Или запустите AppImage
chmod +x ShipTones.AppImage
./ShipTones.AppImage
```

### macOS (.app)
1. Скачайте `ShipTones.dmg` из Releases.
2. Перетащите приложение в папку Applications.
3. Запустите через Finder (может потребоваться разрешение в Системных настройках).

### 🚀 Альтернатива: GitHub Actions
Если релиза ещё нет, зайдите во вкладку **Actions** → последний успешный прогон **Build & Release** → **Artifacts**, там будут бинарники для всех платформ.

## 🛠 Сборка из исходников (для разработки)

Нужно, только если хотите менять код, а не просто пользоваться приложением.

```bash
git clone https://github.com/shipkovivan250-cmd/ShipTones.git
cd ShipTones
pip install -r requirements.txt
python main.py
```

### Требования для запуска из исходников:
- **Python 3.10+**
- **FFmpeg**:
  - **Windows**: скачайте с [ffmpeg.org](https://ffmpeg.org/download.html), положите `ffmpeg.exe` рядом с `main.py` или добавьте в `PATH`
  - **Linux**: `sudo apt install ffmpeg` (Ubuntu/Debian) или `sudo dnf install ffmpeg` (Fedora)
  - **macOS**: `brew install ffmpeg`

### Сборка исполняемых файлов вручную:

#### Windows (.exe)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ShipTones --add-binary "ffmpeg.exe;." --add-data "web;web" --collect-all pywebview --collect-all pythonnet --collect-all clr_loader main.py
```

#### Linux (.AppImage / .deb)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ShipTones --add-data "web:web" --collect-all pywebview main.py
# Для создания .deb используйте dpkg-deb или fpm
```

#### macOS (.app)
```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name ShipTones --add-data "web:web" --collect-all pywebview main.py
```

Готовые файлы появятся в папке `dist/`.

> 💡 **Совет**: Проще использовать GitHub Actions — запушьте изменения в `main`, и сборка запустится автоматически (см. `.github/workflows/release.yml`). Готовые бинарники для всех платформ будут в Artifacts.

## 🚀 Как выпустить новую версию (для владельца репозитория)

Чтобы у пользователей сработала проверка обновлений (кнопка «Проверить обновления» в Настройках), релиз нужно публиковать как **GitHub Release**, а не просто брать файлы из Artifacts:

1. Поднимите `APP_VERSION` в [`config.py`](config.py) (например, `"1.1.0"` → `"1.2.0"`).
2. Закоммитьте и запушьте это изменение в `main`.
3. Создайте и запушьте тег с тем же номером, с буквой `v` впереди:
   ```bash
   git tag v1.2.0
   git push origin v1.2.0
   ```
4. Workflow `.github/workflows/release.yml` автоматически:
   - Соберёт исполняемые файлы для **Windows** (.exe), **Linux** (.deb/.AppImage) и **macOS** (.app/.dmg)
   - Опубликует их как GitHub Release с тегом `v1.2.0`
5. У всех, кто уже пользуется более старой версией, нажатие «Проверить обновления» в Настройках скачает и установит новую версию.

> 💡 **Совет**: Можно также создать Draft Release вручную через веб-интерфейс GitHub, затем запушить тег — workflow автоматически загрузит туда собранные файлы.

## 📖 Использование

1. Вставьте ссылку на трек или плейлист в поле ввода (или перетащите ссылку в окно — **Drag & Drop**).
2. Выберите источник (определяется автоматически по ссылке), папку назначения (кнопка «Обзор…»), **формат аудио** (AAC/MP3/FLAC/Opus) и качество.
3. Выберите режим — «Один трек» или «Плейлист».
4. Нажмите **▶ Начать загрузку**.
5. Готовые треки появятся карточками ниже, лог покажет прогресс. По завершении можно открыть папку с файлами кнопкой **📁 Открыть папку**.

Во вкладке **Плейлисты** можно повторно синхронизировать ранее скачанные плейлисты, а в **Настройках** — число потоков, умные дубликаты, автокаталогизацию и расширенные теги.

## 🏗 Структура проекта

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа, перехват фатальных ошибок |
| `webapp.py` | Мост между интерфейсом и логикой: окно WebView2, JS API |

| `sources/` | **Модули загрузчиков**: YouTube Music, VK, Яндекс |
| └ `youtube_source.py` | Базовый класс для YouTube/YouTube Music |
| └ `ytmusic_source.py` | Специализированный загрузчик YouTube Music |
| └ `vk_source.py` | Загрузчик VK Музыки (в разработке) |
| └ `yandex_source.py` | Загрузчик Яндекс Музыки (в разработке) |

## 📍 Где хранятся данные

Приложение не создаёт файлы рядом с исполняемым файлом. Всё лежит в пользовательской директории:

| ОС | Путь |
|----|------|
| **Windows** | `%APPDATA%\ShipTones\` |
| **Linux** | `~/.config/shiptones/` |
| **macOS** | `~/Library/Application Support/ShipTones/` |

Файлы:
- `shiptones.db` — история загрузок и сохранённые плейлисты (SQLite)
- `shiptones.log` — лог для диагностики ошибок
- `settings.json` — сохранённые настройки (формат, качество, путь загрузки и т.д.)

## ⚠️ Известные проблемы

### При запуске из исходников
- **`ModuleNotFoundError: No module named 'yt_dlp'`** (или `mutagen` / `PIL`) — зависимости не установлены. Установите: `pip install -r requirements.txt`. В готовых бинарниках из релиза этой проблемы нет.

- **`⚠ FFmpeg не найден!`** в логе — актуально только при запуске из исходников:
  - **Windows**: скачайте `ffmpeg.exe` с [ffmpeg.org](https://ffmpeg.org/download.html) и положите рядом с `main.py` или добавьте в `PATH`
  - **Linux**: `sudo apt install ffmpeg` (Ubuntu/Debian) или `sudo dnf install ffmpeg` (Fedora)
  - **macOS**: `brew install ffmpeg`

### При загрузке треков
- **YouTube блокирует загрузки** — приложение автоматически обновляет `yt-dlp` при каждом запуске. Если проблема сохраняется, проверьте интернет-соединение и попробуйте снова.

- **VK/Яндекс Музыка не работают** — эти источники находятся в разработке 🚧. Используйте YouTube Music (работает стабильно).

### Диагностика
Полный traceback любой критической ошибки сохраняется в лог-файле:
- **Windows**: `%APPDATA%\ShipTones\shiptones.log`
- **Linux**: `~/.config/shiptones/shiptones.log`
- **macOS**: `~/Library/Application Support/ShipTones/shiptones.log`
